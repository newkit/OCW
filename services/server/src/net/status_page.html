Open Cycling World

Public test server

This is the public test server of Open Cycling World, a free, open-source indoor cycling game. Everyone who joins rides the same roads at the same time and can talk over voice. It is a test: it may restart or change at any time.

Ride with the desktop app

  1. Download Open Cycling World for Linux, Windows or macOS from the releases page.
  2. In the app open Ride → Join and paste this join link (or start ocw-desktop --join LINK):
{{LINK}}

The link names the server's address and the fingerprint of its certificate; the app checks it when it connects.

Privacy

This page shows counts only: no rider names, no addresses, no positions. The numbers are kept since the server started; "today" is the UTC day. What riding together shares is in the browser app's privacy note.
